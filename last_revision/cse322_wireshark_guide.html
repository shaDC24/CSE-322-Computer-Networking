Core Concepts — Network Monitoring

02

tcpdump — Commands & Output

🇧🇩 বাংলায় ব্যাখ্যা tcpdump হলো Unix-এর command-line packet capture tool। এটা network interface থেকে live packet ধরে বা আগে save করা file পড়তে পারে। sudo দিয়ে run করতে হয় কারণ network interface access করতে root privilege লাগে।
tcpdump — Common Commands
# Basic — eth0 interface থেকে capture শুরু করো
$ sudo tcpdump -i eth0

# Verbose output
$ sudo tcpdump -v -i eth0

# File-এ save করো (live capture → pcap file)
$ sudo tcpdump -i eth0 -w capture.pcap

# Saved file পড়ো
$ tcpdump -r capture.pcap

# Only UDP packets
$ tcpdump "udp"

# Only TCP packets
$ tcpdump "tcp"

# UDP with destination port 53 (DNS requests)
$ tcpdump "udp dst port 53"

# UDP with source port 53 (DNS replies)
$ tcpdump "udp src port 53"

# UDP with port 53 (both DNS requests and replies)
$ tcpdump "udp port 53"

🇧🇩 বাংলায় ব্যাখ্যা Wireshark খুললে ৪টা প্রধান অংশ দেখা যায়: উপরে filter bar, তারপর packet list (সব captured packets), তার নিচে packet details (selected packet-এর layer-by-layer breakdown), এবং সবচেয়ে নিচে hex dump (raw bytes in hex এবং ASCII)।

Capture Options — Promiscuous Mode

  • Promiscuous mode: সব network traffic capture করে (শুধু নিজের নয়)। "Enable promiscuous mode on all interfaces" checkbox।
  • কখন কাজ করে না: Driver support না থাকলে, বা Switched LAN-এ (switch শুধু addressed packets পাঠায়)।
  • Ring Buffer: Huge trace problem solve করে। Define করা যায় কতটা file, কত packets/bytes/time-এ নতুন file create হবে।

Capture Filter vs Display Filter

🇧🇩 বাংলায় ব্যাখ্যা Wireshark-এ দুই ধরনের filter আছে। Capture Filter দিয়ে capture শুরু করার আগেই বলে দেওয়া হয় কি ধরনের packet capture হবে — বাকি packets ধরাই হবে না। Display Filter capture-এর পরে শুধু view পরিবর্তন করে — সব packets trace-এ থাকে, শুধু display-এ filter হয়।

Capture Filter vs Display Filter — Key Differences

Capture FilterDisplay Filter
কখন apply?Capture শুরু হওয়ার আগেCapture-এর পরে (analysis-এ)
Effect?Non-matching packets capture-ই হয় নাসব packets আছে, শুধু view filtered
SyntaxBPF (Berkeley Packet Filter) syntaxWireshark-specific syntax
PowerSimpleMuch more powerful ✓
LocationCapture → Options → Capture filter fieldFilter bar (Ctrl+/ বা top bar)
Save packets?Non-matched packets lost foreverAll packets still saved

Capture Filter Examples (BPF Syntax)

GoalCapture Filter

Two hosts conversationhost 192.168.0.1 and host 10.1.11.1
HTTP porttcp port http
IPv4 onlyip
No broadcast/multicastnot broadcast not multicast

Display Filter — Syntax Structure

Syntax:   Protocol . Field  Operator  Value
Example:  ip       . addr   ==        192.168.1.10
Example:  tcp      . port   ==        80
Example:  http     . request.method  ==  "GET"

Comparison operators:
  == (eq)    != (ne)    > (gt)    < (lt)    >= (ge)    <= (le)

Logical operators:
  && (and)    || (or)    ! (not)    ^^ (xor)

Syntax correct → GREEN highlight
Syntax wrong   → RED highlight

TCP Segment & Flags

🇧🇩 বাংলায় ব্যাখ্যা TCP-তে ৬টা গুরুত্বপূর্ণ flag আছে। প্রতিটা flag ১ bit। এই flags দিয়ে TCP connection-এর state বোঝা যায়। Wireshark-এ এই flags filter করা যায়।

TCP Flags — Wireshark Filter Values

FlagFull NameHex ValueWireshark Filterকি করে
SYNSynchronize0x002tcp.flags == 0x002 বা tcp.flags.syn==1Connection শুরু করা
SYN-ACKSyn + Acknowledge0x012tcp.flags == 0x012Connection accept
ACKAcknowledge0x010tcp.flags == 0x010Data received confirm
FINFinish0x001tcp.flags == 0x001Connection বন্ধ করা
RSTReset0x004tcp.flags == 0x004Connection forcefully বন্ধ
PSHPush0x008tcp.flags.push==1Data এখনই deliver করো
🎯
Exam Tip: tcp.flags == 2 = SYN। tcp.flags == 18 (decimal) = SYN-ACK (0x12 hex = 18 decimal)। TCP 3-way handshake: SYN → SYN-ACK → ACK।

🔍 Scenario 2 — Display filter result count

Q: Wireshark-এ filter http.request apply করার পর status bar-এ দেখাচ্ছে: "Packets: 30180 · Displayed: 45" — এর মানে কি?

Answer:
Packets: 30180 → Total 30,180 টা packet capture হয়েছে (pcap file-এ আছে)
Displayed: 45 → Filter apply করার পরে মাত্র 45 টা HTTP request packet দেখা যাচ্ছে

কেন বাকিগুলো দেখা যাচ্ছে না? Display filter শুধু view change করে — সব 30,180 packets এখনো file-এ আছে। Filter remove করলে আবার সব দেখা যাবে।

তাই HTTP request count = 45।
🛡️ Scenario 3 — Capture filter vs Display filter

Q: একটা analyst Capture filter দিয়ে tcp দিয়ে capture করেছে। পরে সে UDP packets দেখতে চাইছে Display filter দিয়ে। সে কি পারবে? কেন?

Answer: না, পারবে না।

কারণ: Capture filter tcp দিলে capture শুরু হওয়ার সময়ই শুধু TCP packets capture হয়েছে। UDP packets capture-ই হয়নি — pcap file-এ নেই।

Display filter শুধু already captured packets-এর view change করে। যা capture হয়নি, তা display করা সম্ভব না।

সমাধান: আবার capture করতে হবে — এবার Capture filter ছাড়া, বা udp দিয়ে।
📊 Scenario 4 — Protocol Hierarchy কি দেখায়

Q: Statistics → Protocol Hierarchy-তে TCP 91% দেখাচ্ছে। এর মানে কি?

Answer: Total captured packets-এর 91% হলো TCP packets। এর মানে:
→ ওই network-এ বেশিরভাগ traffic TCP-based (HTTP, HTTPS, SSH, etc.)
→ UDP traffic (DNS, video streaming, etc.) মাত্র ~9%

Protocol Hierarchy Statistics → Statistics menu থেকে পাওয়া যায়। এটা নেটওয়ার্কের traffic composition বুঝতে ব্যবহার হয়।
🔴 Scenario 5 — Filter syntax error

Q: Filter bar-এ tcp.port = 80 লিখলে Red হয়। কিন্তু tcp.port == 80 লিখলে Green হয়। কেন?

Answer:
Wireshark Display filter-এ comparison operator হলো double equals == (C-like syntax)।
Single = হলো assignment operator (programming-এ) — Wireshark এটা filter syntax হিসেবে accept করে না।

Rule: Correct syntax → Green background। Wrong syntax → Red background।

Short Questions (1-3 marks) — Teacher Suggested

📝
Teacher-এর suggestion: "Mostly short questions ashbe" — নিচে click করলে answer দেখা যাবে।
Q1. Wireshark কি? এটা tcpdump থেকে কিভাবে আলাদা? (2 marks)
Easy
Wireshark: একটা open-source GUI-based packet sniffer/protocol analyzer। এটা Ethereal tool-এর latest version।

Tcpdump থেকে পার্থক্য:
→ Wireshark GUI; tcpdump CLI
→ Wireshark complex filters support করে; tcpdump simple filters
→ Wireshark protocol decode করে (payload analysis); tcpdump basic analysis
→ Wireshark advanced network interfaces; tcpdump conventional
Q2. Capture Filter এবং Display Filter-এর মধ্যে পার্থক্য লেখো। (2 marks)
Easy
Capture Filter: Capture শুরু হওয়ার আগে set করা হয়। Non-matching packets capture-ই হয় না — trace file-এ থাকে না। BPF syntax use করে। Simple but efficient।

Display Filter: Capture-এর পরে analysis-এ use করা হয়। সব packets trace-এ থাকে, শুধু display filtered হয়। Wireshark-specific syntax। অনেক বেশি powerful।
Q3. Wireshark Interface-এর 4টি প্রধান অংশের নাম ও কাজ লেখো। (2 marks)
Easy
1. Display Filter Bar: Packet display filter লেখার জায়গা।
2. Packet List Panel: সব captured packets-এর list — No., Time, Src, Dst, Protocol, Info।
3. Packet Details Panel: Selected packet-এর layer-by-layer protocol breakdown।
4. Packet Content Panel: Raw hex dump + ASCII representation of selected packet।
Q4. Wireshark-এ HTTP request packet count কিভাবে করবে? (1 mark)
Easy
Display filter bar-এ http.request লিখে Enter press করো। Filter apply হলে status bar-এ "Displayed: X" দেখাবে — সেটাই HTTP request packet count।
Q5. tcp.flags == 0x002 এবং tcp.flags == 0x012 — প্রতিটা কি? (2 marks)
Medium
tcp.flags == 0x002 → SYN packet — TCP connection শুরু করার সময় client পাঠায়।

tcp.flags == 0x012 → SYN-ACK packet — Server-এর response to SYN। 0x012 = SYN (0x002) + ACK (0x010) = 0x012।

3-way handshake: Client → SYN → Server → SYN-ACK → Client → ACK।
Q6. Promiscuous mode কি? কখন কাজ করে না? (2 marks)
Medium
Promiscuous mode: Network adapter-এর এমন একটা mode যেখানে শুধু নিজের IP-addressকৃত packets নয়, নেটওয়ার্কের সব packets capture করা হয়।

কখন কাজ করে না:
→ Driver promiscuous mode support না করলে
→ Switched LAN-এ (switch শুধু addressed packets forward করে, broadcast/multicast ছাড়া অন্যের traffic পাওয়া যায় না)
Q7. Ring Buffer কি? কখন ব্যবহার করা হয়? (1 mark)
Medium
Ring Buffer হলো Wireshark-এর একটা capture feature যা huge trace file-এর সমস্যা সমাধান করে। নির্দিষ্ট সংখ্যক file বা size/time limit define করে automatic নতুন file create করে। পুরানো file overwrite হয় — memory/disk সমস্যা avoid করা হয়।
Q8. Wireshark-এ HTTP payload-এ "keyword" search করার filter কি? Case-sensitivity কি important? (2 marks)
Medium
Filter: http contains "keyword"

হ্যাঁ, case-sensitivity important! contains operator case-sensitive। "Monalisa" আর "monalisa" আলাদা। Exact spelling এবং capitalization match করতে হবে।

Alternative: frame contains "keyword" — পুরো packet (সব layers) search করে।
Q9. Expert Information (Analyze → Expert Information) কি দেখায়? (1 mark)
Hard
Expert Information Wireshark-এর automatic analysis tool যা network issues highlight করে severity অনুযায়ী:
→ Error: Critical issues (malformed packets, TLS errors)
→ Warning: Potential issues (retransmissions, RST, zero window)
→ Note: Notable events (fast retransmission, duplicate ACK)
→ Chat: Normal events (connection established)
Path: Analyze → Expert Information
Q10. tcp.srcport == 80 এবং tcp.dstport == 80 — কোনটা HTTP request এবং কোনটা HTTP response? (2 marks)
Hard
tcp.dstport == 80 → HTTP Request — Client server-এর port 80-এ পাঠাচ্ছে (destination = server)।

tcp.srcport == 80 → HTTP Response — Server port 80 থেকে client-এ পাঠাচ্ছে (source = server)।

সহজ মনে রাখা: Traffic direction = destination হলো "গেলো", source হলো "এলো"।
