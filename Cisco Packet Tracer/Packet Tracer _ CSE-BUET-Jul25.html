Packet Tracer

Preliminaries

IP Address

  • IP Address = Network ID + Host ID
  • Network Address = IP Address AND Subnet Mask

Switch

  • A switch operates at Layer 2 (Data Link Layer) of the OSI model.
  • It uses MAC addresses to forward data to the correct destination within a local network.

Router

  • A router operates at Layer 3 (Network Layer) of the OSI model.
  • It uses IP addresses to route data between different networks.
  • Routers can connect multiple networks together and manage traffic between them.

Cable

  • PC ↔ Switch: Straight
  • Switch ↔ Router: Straight, Fiber
  • Router ↔ Router: Cross, Fiber
  • PC ↔ Router: Cross
  • PC ↔ PC: Cross
  • Switch ↔ Switch: Cross, Fiber

PC

  • Static IP Configuration:
    > ipconfig <ip address> <subnet mask> <default gateway>

  • Discover PC
    > ping <ip address> Ping uses ICMP protocol to test connectivity between devices.

  • Telnet to Router/Switch
    > telnet <ip address> → Need to configure VTY and priviledge password.

Terminal (Router/Switch)

  • Priviledge
    > en

  • Configure
    # conf t

Router

  • Configure a interface
    (config) # int <interface> or (config) # int range <interface range>
    Example: int fa0/0, int range fa0/1-5
    (config-if) # ip address <ip address> <subnet mask>
    (config-if) # no shutdown

  • Static routing
    (config)# ip route <network address> <subnet mask> <interface>
    (Network addresses that the router is not directly connected)
    # show ip route
    (config)# do show ip route

  • Dynamic routing
    (config)# router rip
    (config-router)# network <network address> (Network address that the router is directly connected)

  • Backup
    # copy running-config startup-config or # copy run start

  • Inter-VLAN routing
    (config-if)# interface <interface>.<vlan id>
    (config-subif)# encapsulation dot1Q <vlan id>
    (config-subif)# ip address <ip address> <subnet mask>

  • Credentials
    (config)# enable secret <password>
    (config)# hostname <router name>
    (config)# line console 0
    (config-line)# password <password>
    (config-line)# login
    (config)# line vty 0 4
    (config-line)# password <password>
    (config-line)# login

Switch

  • VLAN Configuration
    (config)# vlan <vlan id>
    (config-vlan)# name <vlan name>
    (config)# interface <interface> or (config)# interface range <interface range>
    (config-if)# switchport mode access
    (config-if)# switchport access vlan <vlan id>

  • Trunk Configuration (Switch to Switch or Switch to Router)
    (config)# interface <interface> or (config)# interface range <interface range>
    (config-if)# switchport mode trunk
    (config-if)# switchport trunk allowed vlan <vlan id list>
