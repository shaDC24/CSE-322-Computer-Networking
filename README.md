# CSE-322 Computer Networking

## Overview

This repository contains course materials, lab files, assignments, study guides, and reference documents for CSE 322 Computer Networking.

## Main directories

- `2105123_NS3_proposal/` - NS-3 project proposal files and supporting documents.
- `Assignment-1/` - Assignment 1 materials, socket programming examples, study guides, and related lecture notes.
- `Cisco Packet Tracer/` - Packet Tracer lab files, online lab captures, cheat sheets, and Packet Tracer study guides.
- `IOT/` - IoT assignments, sample code, quizzes, and study resources.
- `Java/` - Java course material folders covering collections, IO, networking, threads, inheritance, and lambda topics.
- `NS3/` - ns-3 tutorials, exam prep, topology guides, learning guides, and previous assignment files.
- `Papers NS3/` - Research papers, surveys, proposal content, and NS-3-related readings.
- `WireShark/` - Wireshark guides, online lab resources, practice PDFs, and command reference files.
- `advanced_topic/` - Advanced networking topic notes and additional PDFs.
- `extra/` - Extra lab and assignment material, including single-threaded and multi-threaded socket examples.
- `last_revision/` - Revision materials for IoT, Wireshark, NS-3, and advanced networking.

## Root files

- `17QuizSolve(Maybe).pdf` - Likely quiz solutions or practice material.
- `CSE322Quiz_merged.pdf` - Merged quiz or study reference document.
